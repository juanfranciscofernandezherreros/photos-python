# Support

Use GitHub Issues for reproducible bugs and focused feature proposals. Before opening an issue:

1. read the README and the relevant document under `docs/`;
2. confirm the problem on the latest revision;
3. collect sanitized application logs and `docker compose ps` output;
4. remove credentials, cookies, personal file names, and photo content.

Use the security process in [SECURITY.md](SECURITY.md) for vulnerabilities. General self-hosting questions should include the operating system, Docker version, deployment profile, and the smallest configuration needed to reproduce the behavior.
